    Quantum Base Layer

    A base-layer that intercepts every model request and response in InfinityVision. On the way out, it widens sampling for more divergent, associative hypotheses. On the way back, it repairs and normalizes whatever comes back — broken JSON, mixed-language text, malformed LaTeX — so it renders cleanly in Synthesis, the Hypothesis Tree, Data tables, and PDF exports.

    Sampling is capped at each provider's own documented ceiling (e.g. Anthropic 1.0, OpenAI/Gemini 2.0). It never goes higher — beyond that, providers return errors or garbage output, which would break JSON-mode calls used throughout the app (role assignment, scoring, hypothesis generation). "Chaos" below controls how close to that ceiling you get, not a literal 0–100% logic dial.
